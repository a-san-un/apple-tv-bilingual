# Apple TV+ Bilingual Subtitles 手動チェックリスト (Phase1)

目的: Phase1 で追加した特性テストに加えて、拡張の基本挙動が壊れていないことを手動で確認する。

## 1. 再生ページで拡張を起動できる

1. Apple TV+ の任意のエピソード再生ページを開く。
2. 拡張を有効化し、再生ページに `ATV-Bilingual` のオーバーレイが表示されることを確認する。
3. 動画が再生状態になっていること (再生ボタンが「一時停止」に変わっている) を確認する。

期待結果:  
拡張のパネルが表示され、動画と字幕の再生が始まる。

## 2. primary / secondary 言語選択と字幕表示

1. 拡張の設定から primary 言語を `en`、secondary 言語を任意の別言語に設定する。
2. 数秒間再生し、画面上に primary + secondary の字幕が表示されることを確認する。
3. secondary 言語を別の言語に切り替え、数秒後に字幕の secondary 部分が切り替わることを確認する。

期待結果:  
- primary テキストは常に選択した primary 言語で表示される。  
- secondary テキストは切り替えた言語に応じて更新される。

## 3. パネルの開閉

1. パネルの表示/非表示切り替えボタンを操作する。
2. パネルを閉じた状態で、動画上の字幕だけが見えることを確認する。
3. 再度パネルを開き、パネル内の過去字幕ブロックが表示されることを確認する。

期待結果:  
- パネルの開閉操作で、レイアウトが破綻せずに切り替わる。  
- パネルを開いたとき、現在行と履歴行が期待どおり表示される。

## 4. secondary 欠落時の panel primary 補完 (#19 回帰チェック)

1. secondary 字幕が短く欠ける (secondary track に一時的に cue が無い) 区間を含むコンテンツを再生する。
2. 該当区間で、画面上の secondary が消えたときでも、パネルの primary 行が一時的に補完されることを確認する。
3. secondary が復帰したタイミングで、パネルの表示も現行仕様どおりに戻ることを確認する。

期待結果:  
- secondary の短いギャップ時のみ、panel primary が補完される。  
- 補完が不要な区間では、primary/secondary の表示が現行と同じ。  

## 5. シークと履歴

1. 再生中に大きくシーク (10〜30秒程度) を行う。
2. シーク後も primary/secondary 字幕が現在位置と同期していることを確認する。
3. パネルの履歴が新しい content key に切り替わっていることを確認する (別エピソードへ移動した場合)。

期待結果:  
- 大きいシーク後も字幕同期が崩れない。  
- content 切り替え時に履歴バケットが正しく入れ替わる。
