## 手動テストチェックリスト


### 1. 起動と基本表示

- Apple TV+ の任意の再生ページを開く。[^1]
- 拡張を有効にし、パネル・オーバーレイ・字幕表示が初期表示されることを確認する。[^1]
- 再生開始後、primary / secondary が数秒以内に安定して出ることを確認する。[^1]


### 2. 言語切替

- primary を `en`、secondary を別言語にして再生する。[^1]
- secondary 言語を別の候補に切り替え、secondary 表示だけが追従して切り替わることを確認する。[^1]
- secondary を OFF 相当にしたとき、secondary だけが消えて primary は維持されることを確認する。[^1]


### 3. パネルと履歴

- パネルを閉じて、動画側字幕だけが残ることを確認する。[^1]
- パネルを再度開いて、現在行と過去行が崩れずに表示されることを確認する。[^1]
- 数行進めたあと、履歴ブロックが順に積まれることを確認する。[^1]


### 4. seek 後の復帰

- 10〜30秒程度の大きなシークを前後に行う。[^1]
- シーク直後に primary / secondary が現在時刻へ再同期することを確認する。[^1]
- シーク後にパネルの current block と履歴が破綻しないことを確認する。[^1]


### 5. secondary 欠落時の recovery

- secondary が一時的に欠けやすい区間、または track が不安定なタイトルを再生する。[^1]
- secondary が一時欠落したとき、panel primary 補完が破綻せず、復帰後に secondary が戻ることを確認する。[^1]
- 欠落が続く場合でも、無限に点滅したり UI が固まったりしないことを確認する。[^2]


### 6. both-missing recovery

- 可能なら、字幕が両方消えやすい場面やシーク直後の不安定区間を使う。[^2]
- primary / secondary の両方が見えなくなった場合、しばらくして recovery が走り、再表示されることを確認する。[^2]
- recovery が短時間に連打されず、落ち着いて1回ずつ動くことを確認する。[^2]


### 7. エピソード切替 / content 切替

- 同一シリーズ内で別エピソードへ移動する。[^1]
- content key 切替後に旧履歴を引きずらず、新しいエピソードの履歴へ切り替わることを確認する。[^1]
- 旧 secondary track の表示や旧 panel state が残らないことを確認する。[^2]


### 8. restart 経路

- 設定変更や再初期化が起こる操作を行う。[^2]
- restart 後にパネル・字幕・overlay が二重生成されないことを確認する。[^2]
- restart 後に secondary recovery が再び動作し、以後の再生でも字幕が復帰できることを確認する。[^3]


### 9. extension OFF / ON

- 再生中に拡張を OFF にする。[^3]
- panel / overlay / secondary 表示が完全に外れ、ネイティブ字幕へ戻ることを確認する。[^3]
- その後 ON に戻し、字幕・パネル・履歴がクリーンな状態で再構築されることを確認する。[^3]


### 10. playback close

- 再生ダイアログの close ボタンで再生画面を閉じる。[^4]
- 閉じた後に、パネル DOM・残留字幕・overlay が画面に残らないことを確認する。[^4]
- 再度別の再生を開いたとき、前回セッションの履歴や secondary 状態を引き継がないことを確認する。[^4]


### 11. 長時間再生

- 5〜10分程度そのまま再生する。[^2]
- 時間経過で字幕更新が止まらないこと、panel 履歴が極端に重くならないことを確認する。[^2]
- 途中で数回パネル開閉・シーク・言語切替を混ぜても、表示が壊れないことを確認する。[^2][^1]


## 優先度順

まずはこの順で回すのが効率的です。[^2][^1]

1. 起動と基本表示
2. 言語切替
3. seek 後の復帰
4. both-missing / secondary recovery
5. extension OFF / ON
6. playback close
7. エピソード切替
8. 長時間再生

## 記録すると良い観点

各項目で、次の観点をメモすると後で比較しやすいです。[^2][^1]

- 再現したか / しないか
- 何秒後に復帰したか
- UI 残留があったか
- 二重生成があったか
- panel 履歴が壊れたか
- コンソールに recovery / cleanup 系ログが出たか
