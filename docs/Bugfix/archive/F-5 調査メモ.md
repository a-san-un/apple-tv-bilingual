### 🟠 F-5 調査メモ（2026-08-17 夜）: Apple TV+ native 字幕構造の整理

**目的:**  
拡張 OFF 後の native 字幕復元（F-5）に向けて、Apple TV+ native 字幕がどこで描画されているか、何を復元対象とみなすべきかを整理する。

**結論:**
- Apple TV+ native 字幕は、通常 DOM 要素としては取得できない
- `amp-tv-overlay > amp-overlay` の open Shadow DOM 内にも字幕文字は存在しない
- native 字幕の実体は `<video>` に紐づく `TextTrack` / `activeCues` 側で観測できる
- 画面に出ている字幕は、`mode === "showing"` かつ `activeCueCount > 0` の track から特定できる
- したがって F-5 の復元対象は「native 字幕 DOM」ではなく、**拡張が変更した `TextTrack.mode` と `video::cue` 抑制状態**である

**観測結果:**

1. **再生コンテナ / overlay 構造**
   - `#main-video-container` 配下に `<video id="apple-music-video-player">` が存在
   - `amp-tv-overlay` 配下に `amp-overlay` が 3 個存在
   - 各 `amp-overlay` は `open` shadowRoot を持つが、
     - `shadowHtml = null`
     - `descendants = []`
   - 字幕文字・字幕 DOM・canvas は確認できなかった

2. **字幕表示座標のレイヤー**
   - 字幕想定座標に対する `elementsFromPoint()` では、
     `.scrim__clickable`、`.video-player-scrim`、`#main-video-container`、
     `.video-player__content`、`.video-player`、`dialog.playback-view`
     などは取得できる
   - しかし字幕文字そのものを持つ DOM 要素は取得できなかった

3. **TextTrack / activeCues 観測**
   - `video.textTracks` から各字幕 track を取得できる
   - `activeCues` からその瞬間の字幕本文を取得できる
   - hidden な track にも active cue は流れるため、
     **cue があること** と **画面に表示されること** は別
   - 画面表示判定には `mode === "showing"` を見る必要がある

4. **実測ログ例**
   - 例1:
     - `selectedTrack: 日本語 / language=ja / kind=subtitles / mode=showing`
     - `onScreenText: 私は前菜が必要`
   - 例2:
     - `selectedTrack: 日本語 / language=ja / kind=subtitles / mode=showing`
     - `onScreenText: 相手の大学教授の非ばかりを 責め立てたりするんだ`

**F-5 への示唆:**
- native 字幕復元で扱うべきは DOM 復元ではない
- `restoreNativeSubtitles()` の責務は次の 3 点に整理できる
  1. bind 前に保存した `primaryTrackOriginalMode` / `secondaryTrackOriginalMode` に戻す
  2. `atvb-cue-suppress`（`video::cue { visibility: hidden !important; }`）を除去する
  3. 拡張が触っていない track の最終状態は決め打ちしない
- ただし `spa_navigation` 直後など `textTrackCount=0` の瞬間があるため、
  restore の空振り対策として「track 準備待ち」は引き続き主検討対象

**現時点の判断:**
- native 字幕の「見えている文字列」は `showing track + activeCues` で取得可能
- native 字幕の「DOM 要素」は取得不能
- F-5 の主因候補は、restore 対象の誤認よりも **track 未準備タイミング** の可能性が高い
- 実機確認では、OFF 復元後に `mode === "showing"` の native track が再び取れるかを確認項目に含める

**再利用コマンド: 画面表示中の native 字幕を取得**
```js
(() => {
  const video = document.querySelector("#apple-music-video-player, video");
  if (!video) {
    console.warn("[native-subtitle] video not found");
    return null;
  }

  const normalizeText = (text) =>
    String(text || "")
      .replace(/<[^>]+>/g, "")
      .replace(/\s+/g, " ")
      .trim();

  const tracks = Array.from(video.textTracks || []).map((track, index) => {
    const activeCues = Array.from(track.activeCues || []).map((cue) => ({
      id: cue.id || "",
      startTime: cue.startTime,
      endTime: cue.endTime,
      rawText: cue.text || "",
      text: normalizeText(cue.text || ""),
    }));

    return {
      index,
      kind: track.kind || "",
      label: track.label || "",
      language: track.language || "",
      mode: track.mode || "",
      cueCount: track.cues?.length ?? 0,
      activeCueCount: activeCues.length,
      activeCues,
    };
  });

  const showingTracks = tracks.filter(
    (track) => track.mode === "showing" && track.activeCueCount > 0
  );

  const selectedTrack = showingTracks[0] || null;
  const onScreenText = selectedTrack
    ? selectedTrack.activeCues.map((cue) => cue.text).join("\n")
    : "";

  const result = {
    currentTime: video.currentTime,
    onScreenText,
    selectedTrack: selectedTrack
      ? {
          index: selectedTrack.index,
          kind: selectedTrack.kind,
          label: selectedTrack.label,
          language: selectedTrack.language,
          mode: selectedTrack.mode,
          activeCues: selectedTrack.activeCues,
        }
      : null,
    showingTracks: showingTracks.map((track) => ({
      index: track.index,
      kind: track.kind,
      label: track.label,
      language: track.language,
      mode: track.mode,
      text: track.activeCues.map((cue) => cue.text).join("\n"),
    })),
  };

  console.log("[native-subtitle] on-screen text", result);

  if (onScreenText) {
    console.log(`[native-subtitle] 画面表示字幕: ${onScreenText}`);
  } else {
    console.warn("[native-subtitle] mode=showing の active cue が見つかりません");
  }

  return result;
})();
```
