## 主要関数と呼び出し関係

- **`startBilingual(options)`** — 初回起動。video取得→track解決→UI構築の順に実行。`content.js` L2685付近
- **`_restartBilingual()`** — 再起動。`prepareForRestart()` → `startBilingual()` の順
- **`destroyUiHosts()`** — パネル・オーバーレイ・開閉ボタンのDOM破棄。`panel-ui.js` L238に実体
- **`detachForDisabled()`** — 監視停止・トラック解除。`modules/playback-session-cleanup.js` L76付近に実体
- **`prepareForRestart()`** — 再起動前のクリーンアップ。`modules/playback-session-cleanup.js` 内
- **`applyPanelVisibility(open)`** — `panelOpen` に応じた表示切替（右側パネル・オーバーレイ限定）
- **`buildNativeToggle()`** — ネイティブトグルUIの生成（`content.js` 内）
- **`isLanguageSelectionReady()`** — primary/secondary どちらか設定済みかを判定

## 重複実行ガード

`content.js` 先頭（L18〜21付近）に **`window.__atvbContentInjected`** フラグを配置。
既に inject 済みの場合は即 `return` して二重起動を防ぐ（**Bugfix-D ✅実装済み**）。

```js
// 二重 inject ガード（SPA reinject 対策）
if (window.__atvbContentInjected) {
  return;
}
window.__atvbContentInjected = true;
```

## 既知の技術的地雷

- **Top Layer 問題** — Apple TV+の再生コントロールは `::backdrop` 付き top layer。拡張UIは `z-index` では重ねられないケースあり
- **CORS 制限** — 辞書JSON取得は `web_accessible_resources` サイドからフェッチ。直接外部URLへの `fetch` は許可が必要
- **SPAナビゲーション** — tv.apple.com は SPA。ページ遷移ごとに reinject が発生するため、`__atvbContentInjected` ガードが必要
- **字幕トラックたまに遅延** — 再生開始直後は `metadata`/`id3` trackのみの場合あり。`startBilingualWhenTracksReady()` で `addtrack` イベントを待機
- **`panelOpen` の二重管理** — `chrome.storage.local` と `state.panelOpen` の両方に存在。更新時は両方を同時に更新すること
