## 主要ファイルと責務


- **content.js** — 拡張のエントリポイント。state 管理・起動・UI 全体のオーケストレーションを担う
- **background.js** — Apple TV+ タブへの content script 注入を管理する。`window.atvbContentInjected` を評価し、同一 document への再注入を避ける
- **settings-runtime.js** — 設定変更時のランタイム適用。拡張全体の ON/OFF 切り替え経路を扱う
- **panel-ui.js** — 字幕パネル開閉ボタン（`atv-toggle-btn`）の生成・破棄、`destroyUiHosts()`、`applyPanelVisibility()` を担う
- **panel-renderer.js** — 右側字幕パネル本体の DOM 生成・破棄を担う
- **secondary-subtitle-dom.js** — セカンダリ字幕の DOM overlay を管理する
- **subtitle-track-resolver.js** — 字幕トラックを検出し、`TRACK_RESOLVE_RETRY_DELAYS_MS` に従って再試行する
- **cue-controller.js** — cue イベント制御のコア。`destroy()` でトラックの unbind、`secondaryTrackRecovery`、`cueRenderCoordinator` を解放する
- **modules/settings-schema.js** — 設定値を正規化する API を提供する
- **modules/settings-store.js** — `chrome.storage` の読み書きを抽象化する
- **modules/panel-visibility-state.js** — `panelOpen` の永続化を管理する。ストレージキーは `panelOpen`
- **modules/playback-session-cleanup.js** — `detachForDisabled()` と `prepareForRestart()` を提供し、双方で `cueController?.destroy?.()` を呼ぶ
- **modules/playback-startup-coordinator.js** — 再生開始時の起動シーケンスを制御する
- **modules/cue-text.js** — cue 操作ユーティリティ。`findCueAt()`、`formatTime()`、`normalizeSubtitleText()` などの純粋関数を提供する。ES モジュールとして内部 import される
- **modules/vtt.js** — VTT 関連ユーティリティ。時間フォーマット系の純粋関数を提供する。ES モジュールとして内部 import される
- **sync-interval-orchestrator.js** — 字幕同期用インターバルを制御する
- **runtime-observers.js** — `MutationObserver` を含む監視処理を管理する
- **settings-bridge.js** — content script と background 間のメッセージブリッジを担う
- **vtt-normalizer.js** — VTT 字幕を正規化する
- **debug-logger.js** — デバッグログの出力を集約する

## 主要関数と呼び出し関係


- **`startBilingual(options)`** — 初回起動処理。video 取得、track 解決、UI 構築の順に実行する
- **`_restartBilingual()`** — 再起動処理。`prepareForRestart()` の後に `startBilingual()` を実行する。`state.restarting` により多重実行を防ぐ
- **`restartBilingual`** — `_restartBilingual()` を外部公開するための参照
- **`destroyUiHosts()`** — パネル、オーバーレイ、開閉ボタンの DOM を破棄する。`panel-ui.js` の責務
- **`detachForDisabled()`** — 拡張 OFF 時の監視停止・トラック解除を行う。`modules/playback-session-cleanup.js` の責務
- **`prepareForRestart()`** — 再起動前に再利用不可な状態・監視・トラックをクリーンアップする。`modules/playback-session-cleanup.js` の責務
- **`cueController.destroy()`** — cue controller のリソースを明示解放する。`detachForDisabled()` と `prepareForRestart()` の双方から呼ぶ。unbind → `secondaryTrackRecovery.destroy()` → `cueRenderCoordinator.destroy()` の順で解放する
- **`panelUi.applyPanelVisibility(open)`** — `panelOpen` に応じて、右側パネルと字幕オーバーレイの表示を切り替える
- **`isLanguageSelectionReady()`** — primary / secondary のいずれかが設定済みかを判定する

## 重複実行ガード


`content.js` の先頭で **`window.atvbContentInjected`** を使用する。  
`background.js` も同じフラグを評価し、content script の注入済み状態を確認する。

同一 document 上で content script が二重評価・二重注入された場合、`content.js` は即座に return する。これにより、listener、observer、timer、字幕同期処理、UI 初期化経路の重複登録を防ぐ。

SPA 遷移後の画面更新は、フラグを解除して content.js を再実行するのではなく、既存 content script の observer・再初期化経路で処理する。


```js
// background.js の注入済み判定と共有する二重注入ガード。
// 同一 document 上での content.js 二重評価を防ぐ。
if (window.atvbContentInjected) {
  return;
}
window.atvbContentInjected = true;
```

## 既知の技術的地雷


- **Top Layer 問題** — Apple TV+ の再生コントロールは `::backdrop` を伴う top layer になることがある。通常の拡張 UI は `z-index` のみでは重ねられない場合がある
- **CORS 制限** — 辞書 JSON は `web_accessible_resources` を経由して取得する。外部 URL への `fetch` には manifest 側の権限設定が必要
- **同一 document への二重注入** — `background.js` は `window.atvbContentInjected` を評価して content script の注入済み状態を確認する。`content.js` は同フラグで二重評価時に即 return し、listener・observer・timer・UI 初期化の重複を防ぐ
- **SPA ナビゲーション** — Apple TV+ 側の DOM は再マウントされうる。画面更新は既存 content script の observer・再初期化経路で処理する
- **Svelte 再マウント** — Apple TV+ 側の再マウントによりネイティブトグルや overlay の DOM 状態が失われうる。F-1/F-2 の修正経路と observer・再初期化経路を壊さない
- **字幕トラックの遅延** — 再生開始直後は `metadata` / `id3` track のみになる場合がある。`startBilingualWhenTracksReady()` で `addtrack` イベントを待機する
- **`panelOpen` の二重管理** — `chrome.storage.local` と `state.panelOpen` の両方に存在する。変更時は双方を同一値へ更新する
