## フェーズ構成

### Phase 1: UI 安定化

**ゴール**: 動画再生時に UI が妨げ合わず、Debug が常時浮かない状態を作る。

- [ ] [#3] 動画操作レイヤーの重なり解消
- [ ] [#4] ATV DEBUG を字幕パネル下部に統合
- [ ] [#5] options の Debug セクション折り畳み既定化

### Phase 2: 設定モデル整理

**ゴール**: 動画を開いているかどうかで popup / options の表示が変わらず、設定 UI と字幕解決ロジックが分離されていること。

- [ ] [#6] 字幕言語一覧固定化とトラック解決分離
- [ ] [#7] secondaryLang fallback 整合

### Phase 3: ログ基盤整理

**ゴール**: options と字幕パネルが同じログソースを共有し、必要なカテゴリだけを既定表示できること。

- [ ] [#8] Debug ログカテゴリ設計整理
