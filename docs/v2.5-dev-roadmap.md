## 更新方針

- 既存 issue（#3〜#8）は基本的にそのまま使用する。
- ただし、手動検証の結果を踏まえて、**優先順位・フェーズ・完了状態を更新**する。
- 特に、字幕が表示されない、または不安定に見える問題は、レイアウトだけでなく **字幕トラック選択（通常字幕 / forced / captions / 重複）** の影響が大きいことが分かったため、設定モデル整理を前倒しする。
- そのため、従来の「UI 安定化 → 設定整理」の順ではなく、**字幕選択ロジックと UI 安定化を同じ Phase 1 で扱う**。
- なお、[#5](../../issues/5) は `options.html` / `options.js` の修正と関連コミットが確認済みのため、**完了済み** として扱う。

## Phase 1 の補足メモ

### 1. 字幕選択 UI

- popup / options の言語選択肢は、動画ごとの `textTracks` の生データをそのまま出さず、固定一覧ベースで扱う。
- 設定 UI では、`en`, `ja`, `de` のような正規化済み言語コードに対応する **1 言語 1 項目** だけを見せる。
- `English (forced)` のような forced 表記は、UI の直接候補にしない。
- `primaryLang` は必須、`secondaryLang` は空保存を許容し、content 側でブラウザ言語 fallback を適用する。

### 2. content.js 側の字幕トラック解決

- `video.textTracks` には、同一言語で通常字幕・forced 字幕・captions・表記ゆれ付きラベルが混在する場合がある。
- そのため、設定 UI の値と実際の字幕トラック解決は分離して扱う。
- 解決時は `language` / `label` を正規化し、同一言語候補から最適なトラックを選ぶ。
- 優先順位は以下を想定する。
  1. 通常字幕
  2. captions
  3. forced
- forced は内部 fallback 候補として扱い、通常の設定 UI から直接選ばせない。

### 3. 動画レイアウト調整

- `video-player__content` を基準に、動画本体と再生コントロール系を左側の責務としてまとめる。
- 右 30% は字幕パネル専用領域として維持する。
- Apple TV+ 側の一時表示 overlay（例: skip overlay）は常時 DOM に存在しない可能性があるため、状態依存で検証する。

## 実装順メモ

1. `popup.js` / `options.js`
   - 固定言語一覧化
   - `primaryLang` / `secondaryLang` の UI 整理
   - 動画依存の字幕候補表示をやめる

2. `content.js`
   - `secondaryLang` fallback を既存方針どおり維持
   - 字幕トラック解決を正規化
   - forced / captions / 重複トラックを考慮した選択処理に整理

3. レイアウト
   - `video-player__content` 基準の 70 / 30 レイアウトを再確認
   - 動画操作レイヤーの重なりを解消

4. Debug
   - Debug Panel を右字幕パネル側へ統合
   - ログカテゴリ設計を整理
