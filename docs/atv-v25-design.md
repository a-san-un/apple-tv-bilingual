# Apple TV+ Bilingual Subtitles v2.5-dev 設計まとめ

この文書は、Apple TV+ Bilingual Subtitles v2.5-dev の
現状コードで確認できたこと・合意済み仕様・将来拡張案を整理した設計メモです。

---

## 1. 現状コードで確認できたこと

### 1.1 現在の構成

- Chrome 拡張 MV3。
- `background.js`: 外部 API 呼び出し用 Service Worker。
- `content.js`: Apple TV+ 再生画面へ UI を注入するメインロジック。
- `popup.html` / `popup.js`: 簡易設定 UI。
- `options.html`: v2.5-dev では実装済み（別タブの設定画面）。[file:197]

### 1.2 字幕 UI の現状

- 動画コンテナは 70% 幅に縮小。
- 右パネルは 30% 幅で表示。
- 右パネルは「履歴 + 現在 + 未来」の一覧型。
- 各字幕ブロックは primary / secondary の 2 行表示。
- 左下オーバーレイにも現在字幕の 2 行表示。
- パネルは `✕` で閉じ、閉じた時だけ右上 `📋` ボタンで再オープン。

### 1.3 単語ポップアップの現状

- タブは 2 つ: `📖 辞書` と `🤖 AI翻訳`。
- 辞書側: EJDict + Jisho + Tatoeba を組み合わせる設計。
- AI翻訳側: Google Translate の訳文を表示する実装。
- Gemini / Groq / Chrome Built-in AI はまだ未実装。[file:196]

### 1.4 言語設定の現状

- v2.5-dev では `primaryLang` / `secondaryLang` の**一般設定は `chrome.storage.sync` に保存**。[web:18]
- API キー（Google AI Studio / Groq）と Debug ログは `chrome.storage.local` に保存。
- 初期値は `primaryLang = 'en'`, `secondaryLang = 'ja'`。
- `secondaryLang` が空の場合はブラウザ言語にフォールバックする仕様を v2.5-dev で追加。[file:197][web:18]

## 2. 言語設定の設計方針

### 2.1 基本方針

- 今後は popup 中心ではなく、`options.html` を別タブで開く構成に寄せる。
- 初回起動時は簡易ポップアップまたは案内を表示し、必要なら設定画面へ誘導する。
- `primaryLang` は必須設定。
- `secondaryLang` が未設定ならブラウザ言語を採用する（v2.5-dev で実装済み）。[file:197]

### 2.2 `primaryLang` の意味

`primaryLang` は「字幕の主言語（学習している言語）」を表す。

想定フロー:

- `popup.html` または `options.html` でユーザーが設定
  - 例: `primaryLang = 'en'`, `secondaryLang = 'ja'`
- `chrome.storage.sync` に保存
- `content.js` が読み込んで対象の字幕トラックを選ぶ

`primaryLang` 未設定は「ユーザーがまだ主字幕言語を決めていない状態」を意味する。

### 2.3 `primaryLang` 未設定判定の案

#### A案

- 条件: `primaryLang` が未設定
- 長所: シンプル
- 短所: 初回起動時しか効かない

#### B案

- 条件: 動画の `textTracks` に `primaryLang` と一致するトラックが存在しない
- 長所: 「設定はあるが、その動画に字幕がない」を検知できる
- 短所: 実装が少し複雑

#### C案（推奨）

- 条件: `primaryLang` が未設定、または一致する字幕トラックが存在しない
- 長所: 初回未設定と、対象動画に字幕がないケースの両方をカバーできる
- 結論: 将来の案内ロジックは C案ベースが望ましい。[file:196]

## 3. レイアウト確定事項

### 3.1 右字幕パネル（確定方針）

- 履歴一覧を残す。
- 各ブロックは 2 行表示:
  - 1 行目: 学んでいる言語（primary）。
  - 2 行目: 自分の言語（secondary）。
- current 行を明確に強調する。
- current 行には `▶ 再生中` ラベルや再生ボタン風 UI を付ける。
- グレーアウト感は減らし、全体の可読性を上げる。
- 履歴ブロックをクリックしてシークできる現機能は維持。

```text
┌────────────────────────────────────┐
│ 字幕履歴                     [⚙️][✕] │
├────────────────────────────────────┤
│ 12:03                              │
│ I mean, it sounds weird.           │
│ つまり、変に聞こえるけど。          │
│                                    │
│ ▶ 再生中                    [⏵]    │
│ but it's still like making a baby. │
│ でもそれはまだ赤ちゃんを育てるようなもの。│
│                                    │
│ 12:07                              │
│ You have to keep feeding it.       │
│ ずっと面倒を見ないといけない。      │
└────────────────────────────────────┘
```

### 3.2 設定画面（確定方針）

- `options.html` を別タブで開く。
- `options.html` / `options.css` / `options.js` で責務分離。
- ON/OFF はすべてトグルスイッチに統一。
- `primaryLang` は必須。
- `secondaryLang` は未設定時にブラウザ言語を使う。
- 初版は最小構成で始め、AI拡張は段階導入でもよい。[file:197]

```text
┌─────────────────────────────────────────────┐
│ Apple TV+ Bilingual Subtitles     [保存]    │
│ 字幕表示や学習補助の設定を行います          │
├─────────────────────────────────────────────┤
│ 基本設定                                    │
│ 勉強している言語   [ 英語 ▼ ]               │
│ 自分の言語         [ 日本語 ▼ ]             │
│ ※ 未設定ならブラウザ言語を使用             │
├─────────────────────────────────────────────┤
│ 字幕表示                                    │
│ [ON/OFF] 右側の字幕パネルを表示する         │
│ [ON/OFF] 字幕パネルを固定表示する           │
├─────────────────────────────────────────────┤
│ 音声                                        │
│ [ON/OFF] 単語クリック時に音声再生           │
├─────────────────────────────────────────────┤
│ AIツールチップ                              │
│ [ON/OFF] AI自動翻訳ツールチップ             │
│ AI翻訳は字幕本体を置き換えません            │
├─────────────────────────────────────────────┤
│ （将来拡張）AIアシスタント / APIキー /      │
│ プロンプト設定                              │
└─────────────────────────────────────────────┘
```

### 3.3 単語ポップアップ（確定方針）

- ヘッダー: 単語、音声、設定、閉じる。
- 読み: 発音記号。
- グロス: 日本語の短い意味。
- 辞書セクション: 品詞別の意味。
- AIセクション: `説明する / 例 / 文法` タブ + 設定 + 折りたたみ。
- 例文セクション: Tatoeba 例文。
- 単語クリック時に音声再生したい。
- `🔊` ボタンでも再生したい。
- `⚙️` は設定画面への導線候補。
- AIは字幕本体の訳を置き換えず、補助説明として扱う。[file:196]

```text
┌────────────────────────────────────┐
│ broke                    [🔊][⚙️][✕] │
│ /broʊk/                              │
│ 壊れた, 砕けた, 無一文の              │
├────────────────────────────────────┤
│ 📖 辞書                              │
│ Verb      壊す, 砕く, 折る           │
│ Adjective 無一文の, 破産した         │
│ Noun      故障, 休憩                 │
├────────────────────────────────────┤
│ 🤖 [説明する][例][文法] [⚙️][∧]      │
│ …AI応答…                             │
├────────────────────────────────────┤
│ 💬 例文：Tatoeba ↗                   │
│ She broke the window.               │
│ He broke his promise.               │
│ （最大5件）                          │
└────────────────────────────────────┘
```

## 4. options ファイル構成と manifest

### 4.1 推奨ファイル構成

```text
options.html   ← 設定画面のマークアップ
options.css    ← 設定画面の見た目
options.js     ← 設定の読込・保存・状態確認
```

### 4.2 manifest.json 側の設定

```json
{
  "version": "2.5.1",
  "options_ui": {
    "page": "options.html",
    "open_in_tab": true
  }
}
```

- `open_in_tab: true` で設定画面を別タブで開く。
- popup や UI 上の `⚙️` からは `chrome.runtime.openOptionsPage()` を呼ぶ。

## 5. AI プロンプト設計（確定案）

（元ファイルの 6.x セクションを保持）

- 説明タブ / 例文タブ / 文法タブそれぞれに、`<WORD>` / `<CONTEXT>` を使ったプロンプトを定義。
- options.html では「AIプロンプト設定」セクションとして編集 UI を提供。
- プロンプトは「デフォルトに戻す」ボタンで初期化できる。[file:196]

---

## 6. AI 翻訳と AI アシスタントの位置づけ

- AI翻訳はあくまで「ツールチップ用」の補助機能。
- 字幕パネル本体の 2 行字幕を AI で置き換えない。
- AI訳は意訳が入るため、公式字幕との差を確認する用途として扱う。
- 設定画面でも「AI翻訳は字幕本体を置き換えません」と明記する。[file:196]

---

## 7. 再生操作レイヤーと DOM 調整

（元ファイルの 9.x / 12.x を要約）

- 動画本体は 70% 幅に縮め、右 30% を字幕パネル専用領域にする。
- Apple TV+ の再生操作 UI が右パネルに重ならないよう、CSS 上書きを検討。
- 実際の DOM / class 名は DevTools で確認し、壊れない程度に調整する。[file:196]
